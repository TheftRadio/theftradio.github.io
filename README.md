# Theft Radio

A browser radio player: 20 stations of songs from the GTA 6 soundtrack lists, played through Spotify's embed player.

**Open it:** https://theftradio.github.io

- On a computer, log in to Spotify in the same browser for full songs (a free account works).
- On phones Spotify's embedded player only plays 30-second previews, so each station has a *Play in the Spotify app* button that opens its playlist (official Rockstar Games playlists where they exist, fan playlists otherwise).
- The *Mini player* link opens a small window version.
- Station artwork is original, AI-generated for this project. Song playback and metadata come from Spotify.

Fan project, not affiliated with Rockstar Games or Take-Two Interactive.
